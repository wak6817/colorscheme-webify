# colorscheme-webify

some small CSS files you can import to make your website catppuccin frappe themed

there are multiple versions of the project, their CSS files are in `/src/chosen-colorscheme/chosen-version`

# how to use

download the latest version of the project in the releases section and extract the zip file, after that select the colorscheme and version you want (like Catppuccin Mocha Modern), import all the files that folder into your project.

after that just connect the CSS file (or if you selected the pixel art version, connect everything). _if you selected the pixel art version you might need to fix the connections between the audo and audio handler!_

# api

there are 5 classes that you can use in your website: error, warning, success, highlight and info. they will color the text of your HTML tag, you can call them like any other HTML class
